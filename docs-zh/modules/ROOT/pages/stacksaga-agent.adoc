== 概述 (Overview)

StackSaga 包含一套专用的**重试子系统 (Retry Subsystem)**，专门负责对因网络超时或下游服务暂时不可用等瞬时故障而挂起的事务进行异步调度与自动重试。

重试子系统采用了三位一体的集群架构 —— **重试协调器主节点 (Retry-Coordinator-Master)**、**重试协调器从节点 (Retry-Coordinator-Slave)** 以及**编排器重试节点 (Orchestrator Retry-Node)** —— 依托 Murmur3 虚拟令牌环分区算法与长连接 RSocket 协议，在微服务集群多实例之间安全、均匀地分发重试职责。

欲获取完整的架构与工程指南，包括：

* 可重试异常与非可重试异常的判定原则
* 为什么微服务单机内存重试无法保证最终一致性
* 编排器部署模式（标准节点 Standard-Node vs 重试节点 Retry-Node）
* 基于 Murmur3 算法的虚拟令牌环拓扑切分
* RSocket 通信范式与心跳健康探测
* 时间窗口令牌发布与并发竞态消除
* 多地域集群隔离与单元化部署
* 生产级部署拓扑与高可用实践
