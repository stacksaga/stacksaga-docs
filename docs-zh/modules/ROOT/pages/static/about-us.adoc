        <h2>什么是 StackSaga 框架？</h2>
        <p>StackSaga 框架是一个轻量级且高韧性的 Java 开源框架，专为简化微服务架构下的分布式事务构建与治理而设计。它帮助开发者高效落地 Saga 模式，全面保障长业务流程的最终一致性与系统可靠性。</p>
    </section>

    <section>
        <h2>我们的使命</h2>
        <p>我们的使命是为全球开发者提供一个能够极大降低分布式事务心智负担的现代化框架。StackSaga 实现了跨多个微服务的无缝编排、智能错误治理与全链路实时监控。</p>
    </section>

    <section>
        <h2>核心特性</h2>

            <li>开箱即用的可视化链路追踪与故障自愈分析工具。</li>
