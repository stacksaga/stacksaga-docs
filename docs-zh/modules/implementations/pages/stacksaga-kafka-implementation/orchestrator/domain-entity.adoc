= 领域实体与事件溯源 (Domain Entity and Event Sourcing)

[.lead]
*领域实体 (Domain-Entity)* 是编排器端构建 Saga 的第一个基石 — 这是一个强类型对象，负责在步骤之间承载事务的业务状态，并标识该事务属于哪一个特定的 Saga 领域。编排器的所有其他核心组件均通过泛型与该实体类绑定（例如 `{template-class}<OrderDomainEntity, ?>`、`AbstractEventManager<OrderDomainEntity, ?>`）。因此，实现一个新的编排器应从定义领域实体起步，随后依次定义 xref:stacksaga-kafka-implementation/orchestrator/topics-event-manager.adoc[主题与 EventManager]，通过 xref:stacksaga-kafka-implementation/orchestrator/orchestrator-usage.adoc[`{template-class}`] 触发 Saga，并在最后优化 xref:stacksaga-kafka-implementation/orchestrator/properties.adoc[配置属性]。
