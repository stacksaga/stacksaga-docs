= StackSaga Oracle 响应式支持 (即将推出)

[IMPORTANT]
.正在开发与部署中 (Under Active Development)
====
Oracle 数据库支持模块 (`stacksaga-oracle-reactive-support`) 目前正在积极研发与测试部署中，尚未发布到 Maven Central。
本页面提供技术预览与即将推出的 Oracle 响应式事件存储架构指南。
====

== 概述 (Overview)

`stacksaga-oracle-reactive-support` 是计划中的 xref:stacksaga-database-support:overview/database-support-overview.adoc[数据库支持模块] 的 **Oracle 响应式（非阻塞 R2DBC）** 实现。
它将为 StackSaga 引擎提供将 Oracle 数据库作为事件存储所需的一切底层能力，同时也暴露内置端点，供 xref:trace-window:stacksaga-trace-window.adoc[] 控制台查询追踪明细。

// image::stacksaga-database-support:stacksaga-diagram-stacksaga-components-database-support.svg[]

NOTE: 请先阅读 xref:stacksaga-database-support:overview/database-support-overview.adoc[]，以便更好地理解数据库支持模块的职责与核心架构。

[[adding-oracle-support]]
=== 添加 `stacksaga-oracle-reactive-support` 依赖 (计划中)

[NOTE]
====
以下依赖代码段供架构参考，构件将在后续版本发布时正式推送到 Maven Central。
====

一旦正式发布，您将能够按以下方式将该依赖添加到您现有的编排器 (Orchestrator) 应用程序中：

.在 pom.xml 中添加 `stacksaga-oracle-reactive-support` 依赖
[source,xml,subs="attributes+"]
----
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.stacksaga</groupId>
            <artifactId>stacksaga-bom</artifactId>
            <version>{stacksaga-version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
<dependency>
    <groupId>org.stacksaga</groupId>
    <artifactId>stacksaga-oracle-reactive-support</artifactId>
</dependency>
----

IMPORTANT: 推荐使用 http://init.stacksaga.org/[StackSaga Initializer (初始化器)] 获取项目所需的 StackSaga 依赖配置代码段，以确保拥有匹配正确的依赖版本和配置。

NOTE: Oracle R2DBC 驱动 (`com.oracle.database.r2dbc:oracle-r2dbc`) 由 `stacksaga-oracle-reactive-support` 自动传递引入，支持并在 Oracle Database 18c、19c、21c 和 23c 上进行了兼容性验证。
