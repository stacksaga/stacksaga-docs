= Stacksaga Oracle Reactive Support (Coming Soon)

[IMPORTANT]
.Under Active Development & Deployment
====
Oracle Database support (`stacksaga-oracle-reactive-support`) is currently under active development and testing. It has not yet been published to Maven Central.
This page serves as a technical preview and architecture guide for upcoming Oracle reactive event-store capabilities.
====

== Overview

`stacksaga-oracle-reactive-support` is the planned *Oracle reactive (non-blocking)* implementation of the xref:stacksaga-database-support:overview/database-support-overview.adoc[].
It will provide all the necessary facilities for accessing an Oracle Database as the event-store for the Stacksaga engine, and also provide the endpoints for accessing the event-store to see the tracing details from the xref:trace-window:stacksaga-trace-window.adoc[].

// image::stacksaga-database-support:stacksaga-diagram-stacksaga-components-database-support.svg[]

NOTE: read xref:stacksaga-database-support:overview/database-support-overview.adoc[] to have a better understanding of the database support modules like the responsibilities, architecture etc.

=== Adding `stacksaga-oracle-reactive-support` as a dependency (Upcoming)

[NOTE]
====
The dependency snippet below is for reference. Artifacts will be published to Maven Central upon release.
====

Here is the way that you will be able to add the library into your existing orchestrator application as a dependency once released:

.Adding `stacksaga-oracle-reactive-support` as a dependency
[source,xml,subs="attributes+"]
----
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.stacksaga</groupId>
            <artifactId>stacksaga-bom</artifactId>
            <version>{stacksaga-version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
<dependency>
    <groupId>org.stacksaga</groupId>
    <artifactId>stacksaga-oracle-reactive-support</artifactId>
</dependency>
----

IMPORTANT: It is recommended to http://init.stacksaga.org/[StackSaga Initializer] to get the dependency snippets for your project for the StackSaga related dependencies, as it will ensure you have the correct versions and configurations for your project setup.

NOTE: The Oracle R2DBC driver (`com.oracle.database.r2dbc:oracle-r2dbc`) is pulled in transitively by `stacksaga-oracle-reactive-support`, verified against Oracle Database 18c, 19c, 21c and 23c.
