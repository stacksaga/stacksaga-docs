= Stacksaga Postgresql Reactive Support

== Overview

`stacksaga-pg-reactive-support` is the *PostgreSQL reactive (non-blocking)* implementation of the xref:stacksaga-database-support:overview/database-support-overview.adoc[].
it provides all the necessary facilities for accessing a PostgreSQL database as the event-store for the Stacksaga engine, and also provides the endpoints for accessing the event-store to see the tracing details from the xref:trace-window:stacksaga-trace-window.adoc[].

NOTE: The Maven module and artifact names use the `pg` short form (`stacksaga-pg-reactive-support`) rather than `postgresql`, even though this page and the database itself are referred to as PostgreSQL throughout.

image::stacksaga-database-support:stacksaga-diagram-stacksaga-components-database-support.svg[]

NOTE: read xref:stacksaga-database-support:overview/database-support-overview.adoc[] to have a better understanding of the database support modules like the responsibilities, architecture etc.

[[adding-postgresql-support]]
=== Adding `stacksaga-pg-reactive-support` as a dependency

Here is the way that you can add the library into your existing orchestrator application as a dependency.

.Adding `stacksaga-pg-reactive-support` as a dependency
[source,xml]
----
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.stacksaga</groupId>
            <artifactId>stacksaga-bom</artifactId>
            <version>1.0.0-SNAPSHOT</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
<dependency>
    <groupId>org.stacksaga</groupId>
    <artifactId>stacksaga-pg-reactive-support</artifactId>
</dependency>
----

IMPORTANT: It is recommended to http://initializer.stacksaga.org/[StackSaga Initializer] to get the dependency snippets for your project for the StackSaga related dependencies, as it will ensure you have the correct versions and configurations for your project setup.

NOTE: The PostgreSQL R2DBC driver (`org.postgresql:r2dbc-postgresql`) is pulled in transitively by `stacksaga-pg-reactive-support`, verified against PostgreSQL 12 and later, and integration-tested against PostgreSQL 16.
